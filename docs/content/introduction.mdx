stellar is an agent core with the agent left out. What it ships is the
infrastructure: a loop that asks a model, runs whatever the model asked for,
and asks again. All of `core/` is under 2000 lines together — `wc -l core/*.py`
is the measurement, and a test fails the build when it stops being true — and
it imports the standard library and itself, nothing else. The single exception
is `httpx`, in `core/llm.py` alone, because a socket has to come from
somewhere.

Small enough to read top to bottom in one sitting, strong enough for hard tasks
when it is used well. Everything past the loop — providers, rule cards,
transports — is a small file outside `core/` that you can read, copy and
change.

## The robot with one backpack

An agent is a robot with one backpack. Inside: a brain (the model), a toolbox
(the tools), a stack of rule cards (the hooks), a radio (the events) and one
spare pocket (`extra`).

One errand is one `Run`: its own notebook (`run.messages`), its own step count,
its own id, its own spare pocket, and its own rule cards if it wants any. The
robot reads the cards before and after it thinks, and before and after every
tool it picks up. Everything that happens goes out over the radio. When the
model stops asking for tools, the errand is done.

```text
run.pre
  ┌ model.pre → the model answers, a model.delta per streamed Part → model.post
  │   the answer goes in the notebook; for each tool it asked for:
  │     tool.pre → the tool runs, a tool.delta per yielded Part → tool.post
  │     → the result goes in the notebook
  └ again, as long as the last answer asked for tools
run.post
```

Those eight names are the whole schedule. [The loop](/concepts/loop) walks them
one moment at a time.

## Small on purpose

The shape is the feature. Everything here is one of a short list of things:

- **[Twelve nouns](/concepts/nouns)** — `Part`, `ToolCall`, `Message`, `Model`,
  `Tool`, `Hooks`, `Event`, `Events`, `Agent`, `Run`, `ContractError`, `Stop`.
  Nothing else in `core/` gets to be one.
- **[One method](/reference/agent)** — `Agent.run()`. There is never a second.
- **[Three contracts](/concepts/contracts)** — a Model, a Tool, a hook. Two are
  classes, one is a function; all three are async, and all three take the run.
- **[Two control signals](/concepts/control)** — `raise Stop`, and a `tool.pre`
  hook that returns a result. No third one, no boolean to return.
- **[Eight stages](/concepts/loop)** — the loop's moments. A hook name and an
  event name are one word, so the thing you listen for is the thing you can
  change.

Nothing is composed by configuration. Any part is swapped by assignment, even
mid-run: the wiring is read again at the top of every step, so a bad swap is
caught before it runs.
