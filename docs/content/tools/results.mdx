title: What a tool returns
description: Anything at all. One function shapes whatever came back into the one tool message the model reads.

A tool owes no return type. Whatever `execute` hands back — a string, a dict,
a picture, nothing — is shaped into a single tool message stamped with the
call's id, and that message is the next line in the notebook (`run.messages`).

## The seven shapes

| you return | the model gets |
| --- | --- |
| a `str` | that text |
| a `Part` | that one part as the content — a picture with no words |
| a `list[Part]`, every item a `Part` | all of them, in order — text and a picture together |
| a `Message` | the message itself, its role forced to `tool` |
| a `dict`, any other `list`, number, `bool` | `json.dumps` of it |
| `None` | `null`, because that is the JSON for it |
| nothing JSON can hold | `str()` of whatever would not serialise |

An empty list is still JSON, so it arrives as `[]` and not as empty content.
A `Message` you build yourself keeps its own `tool_call_id` if it has one, and
is stamped with the call's otherwise — everything else is always stamped.

```python
import asyncio

from core import Agent, FakeModel, Message, Part, ToolCall, tool


@tool
def pic() -> Part:
    """Hand back a picture."""
    return Part("image", {"url": "https://example.com/a.png"})


@tool
def bag() -> dict:
    """Hand back a dict."""
    return {"n": 1}


two = Message("assistant", "", [ToolCall("c1", "pic"), ToolCall("c2", "bag")])
run = asyncio.run(Agent(FakeModel([two, "done"]), [pic, bag]).run("go"))
told = [m for m in run.messages if m.role == "tool"]
assert told[0].content == [Part("image", {"url": "https://example.com/a.png"})]
assert told[1].text == '{"n": 1}'
```

A streaming tool — an async generator `execute` — does not return at all. Its
result is the **fold** of the parts it yielded: consecutive text parts join
into one, a `meta` part merges into the message's meta, and everything else
lands in the content untouched. That is the same fold a streaming model's
reply goes through.

## The gate grades a result

A tool's result is something you wrote, so a provider grades it before the
next request leaves. An image part on a model whose [profile](/models/profiles)
does not have the word `image` raises `Unsupported` — before the network, at no
cost. The message names the profile and what it can actually read:

```text
Unsupported: texty reads no 'image' part; it reads stream, tools
```

The model's own past turns are replayed as they came and never graded. Yours —
user lines, tool results — are.

## When a tool goes wrong

Run-time mistakes are answers, not crashes. Each of these becomes the tool's
result and the model gets another turn:

| what happened | what the model reads |
| --- | --- |
| the tool raised | `error: ValueError: nope` |
| the model asked for a tool that is not in the toolbox | `error: unknown tool: ghost` |
| the provider could not parse the call's arguments | `error: tool arguments were not valid JSON: {oops` |

A streaming tool that raises halfway is answered for the same way: the error is
the whole result, and the parts it had already yielded are dropped from the
notebook — though each of them rang `tool.delta` on the way past, so anyone
watching [the bus](/events/overview) saw them.

<Note>
  Exactly two exceptions are not turned into results. `Stop` ends the run
  cleanly, and `ContractError` stays loud — a wiring mistake is never something
  to tell the model about. See [stopping and denying](/hooks/stopping).
</Note>

## A hook can answer instead

A [`tool.pre`](/hooks/stages) hook that returns a `str` or a `Message` skips
the tool and *is* its result — same shaping, same id, same next line in the
notebook. That is the whole deny path, and a `Message` means a denial can carry
parts too:

```python
from core import Message, Part, ToolCall, hook


@hook("tool.pre")
async def no_rm(call: ToolCall) -> Message | None:
    """Answer for rm instead of running it."""
    if call.name == "rm":
        return Message("tool", [Part("text", "denied — ask a human first")])
    return None
```
