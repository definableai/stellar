Four steps from an empty folder to an agent that answers you.

<Steps>
  <Step title="Get the code">

    stellar is a repository you clone and work inside. There is nothing to
    `pip install`.

    ```bash
    git clone <your copy of stellar> stellar
    cd stellar
    uv sync
    ```

    You need Python 3.13 or newer. `httpx` is the only dependency it lists.

  </Step>

  <Step title="Bring a key">

    Each provider reads one environment variable. Pick the one you have.

    <Tabs>
      <Tab title="Anthropic">

        ```bash
        export ANTHROPIC_API_KEY=sk-ant-…
        ```

      </Tab>
      <Tab title="OpenAI">

        ```bash
        export OPENAI_API_KEY=sk-…
        ```

      </Tab>
    </Tabs>

    You can pass `api_key=` when you build the model instead, and that wins.
    With neither one you get a `ValueError` naming the variable it wanted.

  </Step>

  <Step title="Write the agent">

    Build the agent once. Call `run()` once per conversation. This script
    needs a key, so our tests do not run it.

    ```python title="hello.py"
    import asyncio

    from core import Agent, tool
    from hooks.steps import Steps
    from models.anthropic import Anthropic


    @tool
    def shout(word: str) -> str:
        """Shout a word."""
        return word.upper()


    agent = Agent(Anthropic("claude-sonnet-5"), [shout])
    agent.hooks.attach(Steps(8))                       # at most eight model turns


    async def main() -> None:
        run = await agent.run("shout hello")
        print(run.messages[-1].text)                   # what the model said last

        again = await agent.run("again, louder",       # the same conversation
                                messages=run.messages, run_id=run.id)
        print(again.messages[-1].text)


    asyncio.run(main())
    ```

    `Anthropic("claude-sonnet-5")` picks the model. `@tool` turns the function
    into a tool. The name comes from the function, the description from its
    docstring, and the arguments from the signature. `Steps(8)` is a rule that
    ends the run after eight model turns.

  </Step>

  <Step title="Run it">

    ```bash
    uv run python hello.py
    ```

    Two lines print. The first is what the model said after `shout` ran. The
    second is its answer to the follow-up. That second `run()` opens on the
    first one's messages and keeps its id, so it is one conversation.

  </Step>
</Steps>

## Running without an API key

`FakeModel` says what you tell it to say, one entry per turn. No network, no
key, and the same loop underneath.

```python run
import asyncio

from core import Agent, FakeModel, Message, ToolCall, tool


@tool
def shout(word: str) -> str:
    """Shout a word."""
    return word.upper()


agent = Agent(FakeModel([
    Message("assistant", tool_calls=[ToolCall("1", "shout", {"word": "hello"})]),
    "HELLO, shouted.",
]), [shout])

run = asyncio.run(agent.run("shout hello"))
print(run.messages[-1].text)
print(run.step)
```

```text output
HELLO, shouted.
2
```

The first entry asks for the tool, the second answers. Ask for one more turn
than you wrote and you get a `ContractError` naming the reply it ran out on.

## The Run object

`agent.run(...)` hands you the `Run`. Four things on it are worth knowing.

- `run.messages` is the whole conversation, in order.
- `run.messages[-1].text` is the answer.
- `run.step` is how many turns the model took.
- `run.id` is this run's id. Pass it back as `run_id=` to carry on.
