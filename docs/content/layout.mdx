The repository is one small `core/` and three folders built on top of it. The
tests keep all four to the rules.

```text
core/       types.py  contracts.py  agent.py  loop.py  events.py
            tool.py  fake.py  llm.py  conformance.py  __init__.py
models/     anthropic/  openai/
hooks/      steps.py  budget.py  permission.py  logging.py
drivers/    transport.py
tests/      test_*.py
docs/       docs.json  content/  check.py
```

## What each folder is for

- `core/` is the engine. The twelve building blocks and the loop, in under
  2000 lines of plain Python.
- `models/` holds one folder per provider. Inside each, `mapping.py` is the
  table of what turns into what and `model.py` is the rest.
- `hooks/` holds the rules that ship in the box: a turn limit, a token
  budget, a tool guard, a logger.
- `drivers/` sends events out of the process. `transport.py` has `sse()` and
  `ws_frames()`.
- `tests/` is plain Python files with asserts in them. No pytest.
- `docs/` is this site. `docs.json` is the menu, `content/` holds the pages,
  and `check.py` is its test.

This is what an import looks like.

```python
from core import Agent, tool
from models.anthropic import Anthropic
from hooks.steps import Steps
```

## How to run the tests

```bash
for f in tests/test_*.py; do uv run python "$f" || exit 1; done
uv run ruff check .
```

Each test is an ordinary script. Run one on its own and it prints what passed.

## The rules we keep

- `core/*.py` is 2000 lines all together, at most.
- `core/` imports the standard library and itself, plus `httpx` in `llm.py`.
- `core/` never names a product or a protocol, comments included.
- `models/`, `hooks/` and `drivers/` import `core`, the standard library,
  `httpx` in `models/`, and a provider's own files.
- Twelve building blocks in `core/`, and nothing else in there gets to be one.
- `Agent` has one method, `run()`.

`tests/test_rules.py` fails the build on the first four. The last two belong
to whoever reviews the change, because no test can see them. `wc -l core/*.py`
is how you check the first one before you push.
