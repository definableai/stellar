title: Provider internals
description: Two files. mapping.py says what crosses the network, model.py does the rest.
---

Stellar ships the half that every HTTP provider shares, as the class
`Provider`. A real provider adds two small files of its own.

`mapping.py` is the table. It has one row for each kind of thing that goes out
or comes back. Text, pictures, tool calls, one whole message, a tool
description, and the reply's header.

`model.py` is the rest. It holds the list of models, the headers, `encode` and
`send`.

## The `Provider` base class

```python
from models.openai import OpenAI

model = OpenAI("gpt-5.6-luna", api_key="sk-...", temperature=0)
```

The model id comes first and is required. `api_key=` beats the environment
variable, and a missing key raises `ValueError` naming the variable to set.
`base_url=` points the same class at a look-alike. Every other keyword is kept
for `encode` to use.

| what | it gives you |
| --- | --- |
| `self.key` | the key, from `api_key=` or from the environment |
| `self.profile` | the [short list](/models/profiles) for this model id |
| `self.params` | the extra keywords this model was built with |
| `self.tool_schemas(run)` | every tool as a plain dict of name, description and parameters |
| `await self.post(path, body)` | one reply, parsed, as a dict |
| `self.sse(path, body)` | the live stream, one dict per data line |
| `self.http` | the HTTP client, one per model, opened when first used |
| `await self.aclose()` | close that client, which is the only thing holding a socket |
| `self.headers()` | yours to write, and what every request carries |

## Retries

`post` and `sse` both try three times. They try again on a dead socket, and on
these statuses: 408, 409, 429, 500, 502, 503, 504, 529. Anything else raises
`ProviderError` on the first try. A 400 or a 401 will not go away if you ask
again.

A stream stops retrying once the first piece is out. There is no way to ask
again without repeating words the reader already saw.

## A mapping row

Here is the picture row, from `models/anthropic/mapping.py`.

```python
def image(p: Part) -> dict:
    d = p.data                          # {"url": …} or {"media_type": …, "data": …}
    source = ({"type": "url", "url": d["url"]} if "url" in d else
              {"type": "base64", "media_type": d["media_type"], "data": d["data"]})
    return {"type": "image", "source": source}


OUT = {"text": text, "image": image}        # Part.type -> block; else passthrough
```

It turns one `Part` into the block Claude expects. `OUT` is looked up by the
part's type. A type that is missing falls to `passthrough`, which sends the
part back exactly as it came.

[OpenAI](/models/openai), are about two hundred lines each. Copy one.
