`drivers/transport.py` takes an async iterator of `Event`s and gives you
strings. It knows no framework. Hand the strings to FastAPI's
`StreamingResponse`, a Starlette websocket, aiohttp, whatever you run. stellar
ships no server of its own.

The event log does the hard half. One run's events, replayed from `since` and
then live, ending on that run's `run.post`. These two only wrap them.

## sse()

```python
from drivers.transport import sse

async def sse(events) -> AsyncIterator[str]: ...
```

Server-Sent Events. One frame per event. An `id:` line carries the seq. A
`data:` line carries the whole record as one JSON object. A blank line ends the
frame.

<ParamField path="events" type="AsyncIterator[Event]" required>
  Normally `agent.events.stream(run_id=...)`, but anything that yields `Event`s
  will do.
</ParamField>

<ResponseField name="frames" type="AsyncIterator[str]">
  One string per event, each already ending in the blank line SSE wants.
</ResponseField>

A whole run of `Agent(FakeModel(["ok"]))` is five frames. Here is the `id:` line
of each one, with the event name read out of its JSON.

```python run
import asyncio
import json

from core import Agent, FakeModel
from drivers.transport import sse


async def main():
    agent = Agent(FakeModel(["ok"]))
    frames = sse(agent.events.stream(run_id="r1"))
    job = asyncio.create_task(agent.run("say ok", run_id="r1"))
    async for frame in frames:
        head, data = frame.splitlines()[:2]
        print(head, json.loads(data[5:])["name"])
    await job


asyncio.run(main())
```

```text output
id: 0 run.pre
id: 1 model.pre
id: 2 model.delta
id: 3 model.post
id: 4 run.post
```

The third frame, whole:

```text
id: 2
data: {"seq": 2, "name": "model.delta", "data": {"type": "text", "data": "ok"}, "source": "loop", "run_id": "r1", "ts": 1789024047.314986}

```

The event name rides inside the JSON. There is no `event:` line, and every frame
is a plain `message`.

<Note>
  The seq is the cursor. A browser that drops hands its last id back as
  `Last-Event-ID`. Reopen with `stream(run_id=rid, since=int(last) + 1)` and the
  client misses exactly what the drop cost.
</Note>

## ws_frames()

```python
from drivers.transport import ws_frames

async def ws_frames(events) -> AsyncIterator[str]: ...
```

Websocket text frames. One whole event per frame and nothing around it. The same
records, without the `id:` line and without the blank one, because the frame
boundary is the websocket's job. What follows `data: ` above is one whole
websocket frame.

<ParamField path="events" type="AsyncIterator[Event]" required>
  The same iterator `sse()` takes.
</ParamField>

<ResponseField name="frames" type="AsyncIterator[str]">
  One JSON object per frame, with no trailing newline.
</ResponseField>

Both call `dump(event)`, which is `json.dumps(asdict(event), default=str)`. That
is the whole record, nested `Message`s and `Part`s and all. Anything JSON cannot
hold falls back to its `str`.

<Warning>
  A ceiling marked in the source. `asdict` copies the payload on every frame, all
  the way down. Write records to the log, not live handles.
</Warning>

See also: [sending events to a browser](/events/transport).
