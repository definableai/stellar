`Model` and `ProviderModel` are the contracts, in `core/contracts.py`.
`Provider`, `Profile`, `Fallback` and the two exceptions are in `core/llm.py`.
That is the one file in core that speaks httpx. `FakeModel` is in
`core/fake.py`. Every name here comes out of `core`.

## Model

```python
from core import Model

class Model:
    async def invoke(self, run: Run) -> Message: ...
```

The thing your agent asks. Write an async `invoke` and hand back one assistant
message.

<ParamField path="run" type="Run" required>
  `run.messages` is the conversation. `run.agent` holds the tools and the hooks.
</ParamField>

<ResponseField name="message" type="Message">
  One assistant `Message`. Anything else raises `ContractError` from the loop.
</ResponseField>

Nothing asks what your class inherits from. Any object whose own class writes an
async `invoke(run)` passes `check()`. The base raises
`NotImplementedError("invoke")`.

## ProviderModel

```python
from core import ProviderModel

class ProviderModel(Model):
    def encode(self, run: Run) -> Any: ...
    def send(self, run: Run, body: Any) -> AsyncIterator[Part]: ...
    async def invoke(self, run: Run) -> Message: ...
```

A `Model` in two steps. `encode` builds the request and only translates, so it
is easy to test. `send` owns the network, and retries live there.

### ProviderModel.encode()

```python
def encode(self, run: Run) -> Any: ...
```

The request body, built from the run. That is every message plus
`run.agent.tools`, and `send()` never builds it again. Unwritten, it raises
`NotImplementedError` carrying the skeleton to copy.

### ProviderModel.send()

```python
def send(self, run: Run, body: Any) -> AsyncIterator[Part]: ...
```

An async generator that yields the reply as `Part`s. A provider that does not
stream yields the parts off its one response, and core cannot tell the
difference.

<ParamField path="run" type="Run" required>
  Whatever the body left out. `run.id`, `run.extra`, the agent.
</ParamField>

<ParamField path="body" type="Any" required>
  Exactly what `encode()` built.
</ParamField>

### ProviderModel.invoke()

```python
async def invoke(self, run: Run) -> Message: ...
```

Encode, send, join. Each `Part` runs the `model.delta` hooks, joins into the
growing message, then goes out as a `model.delta` event. A `send` that yields
something other than a `Part` raises `ContractError`.

## Provider

```python
from core import Provider

class Provider(ProviderModel):
    url: ClassVar[str]
    env: ClassVar[str | None]
    PROFILES: ClassVar[dict[str, Profile]] = {}

    def __init__(self, model: str, *, api_key: str | None = None,
                 base_url: str | None = None, profile: Profile | None = None,
                 **params) -> None: ...
```

The other half of every adapter. A key, a profile, one HTTP client. Set `url`,
`env` and `PROFILES` on your subclass, then write `headers`, `encode` and
`send`.

<ParamField path="model" type="str" required>
  The model id. Positional and required, so there is no silent default.
</ParamField>

<ParamField path="api_key" type="str | None" default="None">
  Beats the environment. Otherwise `os.environ[env]` is read, and `env = None`
  means no key at all.
</ParamField>

<ParamField path="base_url" type="str | None" default="None">
  Point the same class at a compatible clone. Defaults to the class's `url`.
</ParamField>

<ParamField path="profile" type="Profile | None" default="None">
  Override what this id can do. Defaults to `lookup(model)`.
</ParamField>

<ParamField path="params" type="**Any">
  Every extra keyword is kept in `self.params` for `encode` to write into the
  body.
</ParamField>

Raises `ValueError(f"no API key: pass api_key= or set {env}")` when `env` names
a variable and neither it nor `api_key=` has one.

<Expandable title="attributes">
  <ResponseField name="url" type="ClassVar[str]">
    The default base URL for the class.
  </ResponseField>
  <ResponseField name="env" type="ClassVar[str | None]">
    The key's variable. `None` means no key is needed.
  </ResponseField>
  <ResponseField name="PROFILES" type="ClassVar[dict[str, Profile]]" default="{}">
    The rows off the provider's docs, keyed by id prefix.
  </ResponseField>
  <ResponseField name="key" type="str">
    The key that was found, or the empty string when `env` is `None`.
  </ResponseField>
</Expandable>

### Provider.headers()

```python
def headers(self) -> dict: ...
```

What every request carries, the key included. It raises
`NotImplementedError("headers")` until you write it.

### Provider.invoke()

```python
async def invoke(self, run: Run) -> Message: ...
```

`accept(run)` first, then core's own encode, send and join.

### Provider.accept()

```python
def accept(self, run: Run) -> None: ...
```

Refuse now what the API would refuse later. A picture the model cannot read
never costs a round trip.

<ParamField path="run" type="Run" required>
  Its tools, and every line you wrote. The model's own messages are skipped.
</ParamField>

Raises `Unsupported` when the agent has tools and `"tools"` is not in the
profile. It raises again when a content `Part` has a type in neither the profile
nor `ALWAYS`. `ALWAYS` is the frozen set `text`, `tool_call`, `meta`, which core
handles itself.

<Warning>
  A feature named after a `Part` type lets you send that `Part`. That is the
  whole check.
</Warning>

### Provider.lookup()

```python
@classmethod
def lookup(cls, model: str) -> Profile: ...
```

The row for this id. It is the longest key in `PROFILES` that the id starts
with, so `gpt-5.6-luna-2026-08-01` finds `gpt-5.6-luna`. An unknown id logs a
warning and gets `replace(ANY, id=model)`, never an error.

<ResponseField name="profile" type="Profile">
  The matching row, or `ANY` renamed to the id you asked for.
</ResponseField>

### Provider.tool_schemas()

```python
def tool_schemas(self, run: Run) -> list[dict]: ...
```

The tools as plain dicts, one `{"name", "description", "parameters"}` per tool.
`encode` renames the keys its own API wants.

### Provider.http

```python
@property
def http(self) -> httpx.AsyncClient: ...
```

One client per instance, opened on first use. A new event loop gets a new
client, because a connection pool does not outlive the loop that made it. The
old one is closed if that loop still runs. Timeouts are
`httpx.Timeout(10, read=600)`.

### Provider.aclose()

```python
async def aclose(self) -> None: ...
```

Close the client, if one was ever opened. Nothing else holds a socket.

### Provider.post()

```python
async def post(self, path: str, body: dict) -> dict: ...
```

One reply as a dict, in up to three tries. A status in
`RETRY = {408, 409, 429, 500, 502, 503, 504, 529}` or a dead socket earns
another go, after `retry-after` or the attempt number.

<ResponseField name="body" type="dict">
  The parsed JSON of the first answer under 400.
</ResponseField>

Raises `ProviderError(status, text[:200])` on a refusal it will not retry, and
`ProviderError(None, ...)` when the socket never opened after three tries.

### Provider.sse()

```python
async def sse(self, path: str, body: dict) -> AsyncIterator[dict]: ...
```

The event stream, one dict per `data:` line. Comments, blank lines and `[DONE]`
are skipped. It retries like `post`, but only up to the first chunk. A piece
already handed over cannot be replayed. A data line that is not JSON raises
`ProviderError(None, ...)`.

<Note>
  `post` and `sse` are where tests plug in. Override either to feed an adapter
  canned traffic. See [testing an adapter](/models/testing).
</Note>

## Profile

```python
from core import Profile

Profile(id, context, max_output, features=frozenset())
```

One row off the provider's docs. It says what one model id can do. A frozen
dataclass, so `dataclasses.replace` makes a variant.

<ResponseField name="id" type="str" required>
  The id this row describes.
</ResponseField>

<ResponseField name="context" type="int" required>
  The input window, in tokens.
</ResponseField>

<ResponseField name="max_output" type="int" required>
  The default max output tokens `encode` writes, unless one of your params says
  otherwise.
</ResponseField>

<ResponseField name="features" type="frozenset[str]" default="frozenset()">
  The shipped words are `image`, `document`, `thinking`, `tools`, `stream`,
  `tool_stream`, `json` and `system`.
</ResponseField>

### Profile.\_\_contains\_\_()

```python
def __contains__(self, feature: str) -> bool: ...
```

`"image" in profile` is the whole API. A router asks it, and `accept()` asks it
of every `Part`.

```python run
from core import ANY

print("image" in ANY)
```

```text output
True
```

## ANY

```python
from core import ANY
```

The profile an unknown id gets, after the warning. It is
`Profile("unknown", 128_000, 4096, ...)` with all eight feature words.
`lookup()` hands back a copy renamed to the id you asked for.

## Fallback

```python
from core import Fallback

class Fallback(Model):
    def __init__(self, first: Model, *rest: Model) -> None: ...
```

Ask each model in turn. The first one that takes the run and answers wins. It is
a `Model` made of `Model`s, so it nests and it mixes providers.

<ParamField path="first" type="Model" required>
  One `Model` at least. The one you would rather use.
</ParamField>

<ParamField path="rest" type="*Model">
  The others, in the order you want them tried.
</ParamField>

<ResponseField name="models" type="tuple[Model, ...]">
  `(first, *rest)`, in that order.
</ResponseField>

### Fallback.invoke()

```python
async def invoke(self, run: Run) -> Message: ...
```

Down the row until one answers. It catches two refusals and nothing else.
`Unsupported` from `accept()`, before any byte, and `ProviderError` from the
provider, with its retries already spent. Each skip goes out as a `model.skip`
event with the refusal's own words and `source=f"model:{name}"`. The last model
is asked without that catch, so its error reaches you as itself. Any other error
is raised.

<Warning>
  Two limits, marked in the source. A provider that is down is retried in full
  at every step before the next one is asked. And a stream that dies after its
  first piece falls through like any other refusal. The event log then carries
  pieces from a model that never answered.
</Warning>

## FakeModel

```python
from core import FakeModel

class FakeModel(ProviderModel):
    def __init__(self, script: list[Message | str]) -> None: ...
```

A model that reads its answers off a list you wrote. No network, no key. It is a
`ProviderModel`, so each reply is taken apart and streamed as `Part`s. Your
tests take the path a real adapter takes.

<ParamField path="script" type="list[Message | str]" required>
  The replies to hand back, one per turn. It is copied, so your list is left
  alone. A `str` becomes an assistant line.
</ParamField>

<ResponseField name="script" type="list[Message | str]">
  What is left. `send` takes the front of it per turn.
</ResponseField>

### FakeModel.send()

```python
async def send(self, run: Run, body: Any) -> AsyncIterator[Part]: ...
```

Yields the entry's content parts in order. Then one `Part("tool_call", call)`
per `ToolCall` on it. Then one `Part("meta", …)` if it carries any meta.
`encode` builds nothing and hands back `None`.

Raises `ContractError(f"FakeModel script exhausted after reply {run.step - 1}")`
when a run asks for one more turn than you wrote.

## ProviderError

```python
from core import ProviderError

class ProviderError(RuntimeError):
    def __init__(self, status: int | None, detail: str) -> None: ...
```

The provider said no. The message reads `f"{status or 'no status'}: {detail}"`.

<ResponseField name="status" type="int | None">
  The HTTP status, or `None` when there was none. A dead socket, a broken chunk,
  an error event inside a stream.
</ResponseField>

## Unsupported

```python
from core import Unsupported

class Unsupported(ValueError): ...
```

This model cannot do what the run asks. `accept()` says so before anything is
sent. `Fallback` catches it and moves on, and nothing else does.

See also: [writing a provider](/models/provider) and
[fallback and routing](/models/fallback).
