The data plane, in `core/events.py`. Emitting never blocks and never fails — a
listener that raises is logged to the `core.events` logger and the next one
still hears the event. A hook can change the run or stop it; a listener can only
watch.

## Event

```python
from core import Event

Event(seq, name, data=None, source=None, run_id=None, ts=time.time())
```

One thing that happened: numbered, named, stamped. A dataclass, so
`dataclasses.asdict` puts one on a wire.

<ResponseField name="seq" type="int" required>
  Per-bus, monotonic, starts at 0. This is the cursor a dropped reader hands
  back.
</ResponseField>

<ResponseField name="name" type="str" required>
  The dotted name — the loop's eight, or anything you emit.
</ResponseField>

<ResponseField name="data" type="Any" default="None">
  Whatever rode along; stored as-is, not copied.
</ResponseField>

<ResponseField name="source" type="str | None" default="None">
  Who said it: `"loop"`, a tool's name, you.
</ResponseField>

<ResponseField name="run_id" type="str | None" default="None">
  The run it belongs to, or `None` for bus-wide.
</ResponseField>

<ResponseField name="ts" type="float">
  When it was stamped, as `time.time()` — a fresh reading per event
  (`field(default_factory=time.time)`), and `emit()` passes its own.
</ResponseField>

## Events

```python
from core import Events

class Events:
    def __init__(self) -> None: ...
```

The radio (`Events`). Emit into it, listen to it, stream it. Takes no arguments;
one bus per agent, and every run that agent starts rides it.

<ResponseField name="seq" type="int">
  The next sequence number, counting from 0.
</ResponseField>

<ResponseField name="log" type="list[Event]">
  Every event this bus ever carried, in order. `stream()` replays out of it.
</ResponseField>

<ResponseField name="listeners" type="list[tuple[Callable[[Event], Any], str, str | None]]">
  One entry per listener: the function, the prefix it hears, and the one
  `run_id` it wants or `None`.
</ResponseField>

<Warning>
  The log and the stream queues are unbounded — one bus per agent, one process.
  Both are marked as ceilings in the source; cap them when that stops being
  true.
</Warning>

### Events.emit()

```python
def emit(
    self,
    name: str,
    data: Any = None,
    source: str | None = None,
    run_id: str | None = None,
) -> Event: ...
```

Stamp it, keep it, tell everyone. Never blocks, never raises — a listener's sins
stay its own.

<ParamField path="name" type="str" required>
  Dotted event name. The loop uses the eight stage names; you use anything.
</ParamField>

<ParamField path="data" type="Any" default="None">
  Whatever should ride along; stored as-is.
</ParamField>

<ParamField path="source" type="str | None" default="None">
  Who is speaking — `"loop"`, a tool's name, or yours.
</ParamField>

<ParamField path="run_id" type="str | None" default="None">
  Pin the event to one run, or `None` for bus-wide. `Run.emit()` fills this in
  with its own id, which is the usual way in.
</ParamField>

<ResponseField name="event" type="Event">
  The `Event`, already numbered and already appended to `log`.
</ResponseField>

### Events.listen()

```python
def listen(
    self,
    fn: Callable[[Event], Any],
    prefix: str = "",
    run_id: str | None = None,
) -> Callable[[Event], Any]: ...
```

Hear every matching event, synchronously.

<ParamField path="fn" type="Callable[[Event], Any]" required>
  Any sync callable of one `Event`; what it returns is dropped.
</ParamField>

<ParamField path="prefix" type="str" default='""'>
  `""` hears everything, `"tool"` hears `tool.*`. A prefix stops at a dot, so
  `"tool"` never hears `toolbox.x`.
</ParamField>

<ParamField path="run_id" type="str | None" default="None">
  The one run it wants, or `None` to hear the whole bus.
</ParamField>

<ResponseField name="fn" type="Callable[[Event], Any]">
  The same function, so `listen` decorates.
</ResponseField>

Raises `ContractError` on an `async def`: `emit()` never awaits. An async
consumer takes `stream()` instead.

### Events.detach()

```python
def detach(self, fn: Callable[[Event], Any]) -> None: ...
```

Stop telling `fn` anything, from every prefix and run it was filed under.
Matched by equality. Never was listening? Then nothing happens.

### Events.stream()

```python
async def stream(
    self,
    run_id: str | None = None,
    prefix: str = "",
    since: int = 0,
) -> AsyncIterator[Event]: ...
```

The log from `since`, then live — no gap, no doubles, in seq order. The live
listener goes on before the log is read, so an event landing mid-replay waits in
a queue instead of falling between the two.

<ParamField path="run_id" type="str | None" default="None">
  `None` watches the whole bus; an id watches that one run only.
</ParamField>

<ParamField path="prefix" type="str" default='""'>
  `""` hears everything, `"tool"` hears `tool.*` — in the replay and live alike.
</ParamField>

<ParamField path="since" type="int" default="0">
  The first `seq` worth replaying; `0` is the whole log. It trims the replay,
  never the live tail.
</ParamField>

<ResponseField name="events" type="AsyncIterator[Event]">
  An async iterator. Given a `run_id` it hears that whole run and ends on its
  `run.post`, prefix or no prefix, so a reader never hangs on a finished run.
  Without one it never ends.
</ResponseField>

<Note>
  The replay is why the race does not matter — a reader that opens the stream
  after the run started, or after it finished, still gets the whole run in
  order.
</Note>
