---
title: Hook stages
description: The eight moments a hook can listen for, what each one hands you, and a working rule for each.
---

A stage is one moment in a run. There are eight of them and nothing else is
a moment. They are also the names your agent writes in its
[event log](/events/overview), so one word covers both.

| stage | what it hands you | what a return changes |
| --- | --- | --- |
| `run.pre` | the last message, once, before the first turn | that message |
| `model.pre` | every message, before every model call | the whole conversation, for good |
| `model.delta` | one streamed piece, before it joins the reply | that piece |
| `model.post` | the reply, after every model call | the reply that gets written down |
| `tool.pre` | one tool call, before the tool runs | a different call, or an answer that skips the tool |
| `tool.delta` | one piece a streaming tool yielded | that piece |
| `tool.post` | the call and its answer | the answer |
| `run.post` | the last message, once, at the very end | nothing, the job is over |

## run.pre

Runs once, on the last message, before the first turn. A good place to put
words in the user's mouth.

```python
from core import Message, hook


@hook("run.pre")
async def house_style(message: Message) -> Message:
    """Add the house rule to whatever was asked."""
    return Message("user", f"{message.text}\n\nAnswer in one sentence.")
```

## model.pre

Runs before every model call, holding every message. This is the stage that
edits history, and what it returns sticks.

```python
from core import Message, hook


@hook("model.pre")
async def trim(messages: list[Message], run) -> list[Message]:
    """Once the conversation is long, keep the first line and the last twenty."""
    return messages if run.step <= 3 else messages[:1] + messages[-20:]
```

## model.delta

One streamed piece, before it joins the reply. Your hook goes first, so what
joins is what you handed back.

```python
from core import Part, hook

SECRET = "sk-live-000"


@hook("model.delta")
async def redact(part: Part) -> Part | None:
    """Scrub a key out of the stream before anything writes it down."""
    if part.type != "text" or SECRET not in part.data:
        return None
    return Part("text", part.data.replace(SECRET, "[redacted]"))
```

<Warning>
  A piece is only a piece. A secret split across two of them slips past this
  rule. For a whole-answer rule, use `model.post`.
</Warning>

## model.post

The finished reply, before it is written down. Returning `None` leaves it
alone, so changing it in place is the lightest way to tag one.

```python run
import asyncio

from core import Agent, FakeModel, Message, hook


@hook("model.post")
async def stamp(answer: Message, run) -> None:
    """Write the turn number onto the reply about to be written down."""
    answer.meta["step"] = run.step


agent = Agent(FakeModel(["hello"]))
agent.hooks.attach(stamp)
run = asyncio.run(agent.run("hi"))
print(run.messages[-1].meta)
```

```text output
{'step': 1}
```

## tool.pre

Before every tool. Return a `ToolCall` and that call runs instead. Return a
string or a `Message` and the tool is skipped, and your answer is its
result.

```python run
import asyncio

from core import Agent, FakeModel, Message, ToolCall, hook

ALLOWED = {"read", "search"}


@hook("tool.pre")
async def only_reading(call: ToolCall) -> str | None:
    """Anything not on the list is refused, and never runs."""
    if call.name in ALLOWED:
        return None
    return f"denied: {call.name} is not on the list"


asked = Message("assistant", "", [ToolCall("c1", "write", {"path": "a"})])
agent = Agent(FakeModel([asked, "I could not write it."]))
agent.hooks.attach(only_reading)
run = asyncio.run(agent.run("write a file"))
print(next(m.text for m in run.messages if m.role == "tool"))
```

```text output
denied: write is not on the list
```

## tool.delta

One piece a streaming tool yielded. Because a hook may raise, this is also
where you cut a runaway tool short.

```python
from core import Part, Stop, hook


@hook("tool.delta")
async def cap(part: Part, run) -> None:
    """End the run once one tool has streamed more than ten thousand letters."""
    if part.type == "text":
        run.extra["streamed"] = run.extra.get("streamed", 0) + len(part.data)
    if run.extra.get("streamed", 0) > 10_000:
        raise Stop
```

## tool.post

The call and its answer, together. What you return is written down as it is,
so carry the `tool_call_id` across yourself.

```python
from core import Message, ToolCall, hook


@hook("tool.post")
async def shorten(call: ToolCall, result: Message) -> Message | None:
    """Keep a huge answer out of the conversation, and say that it was cut."""
    if len(result.text) <= 4_000:
        return None
    return Message("tool", result.text[:4_000] + "\n... cut",
                   tool_call_id=result.tool_call_id)
```

## run.post

Once, at the very end. It runs after a clean finish, after a `Stop`, and
after a crash. Nothing you return changes anything.

```python
from core import Message, hook


@hook("run.post")
async def done(last: Message, run) -> None:
    """One line when the job ends, however it ended."""
    print(f"ended at step {run.step}: {last.text[:60]}")
```
