title: Hooks
description: The control plane — an async function, tagged with the moments it listens for, that can change the run or end it.
---

A hook is an async function tagged with the stages it listens for. It fires
inline, in the middle of the run, and what it returns replaces the payload it
was handed.

```python
from core import Agent, FakeModel, ToolCall, hook


@hook("tool.pre")
async def no_rm(call: ToolCall) -> str | None:
    """Answer for rm instead of letting it run."""
    if call.name == "rm":
        return "denied"                 # the tool is skipped; this is its result
    return None


agent = Agent(FakeModel(["done"]))
agent.hooks.attach(no_rm)               # every run of this agent
```

`agent.hooks` is the stack of cards every run of that
[agent](/reference/agent) reads. `run.hooks` is the lane nobody else can see:
`run.hooks.attach(no_rm)` files a card for one conversation only.

## The return is the contract

Return `None` and the payload is left alone. Return the stage's own type and
that value is what the next hook hears, and what the loop uses. Return anything
else and it is a `ContractError` naming your function, the stage, and what to
return instead:

```text
stringly at model.post returned str; return Message, or None to leave it alone
```

In ring order the stages are [`run.pre`](/hooks/stages),
[`model.pre`](/hooks/stages), [`model.delta`](/hooks/stages),
[`model.post`](/hooks/stages), [`tool.pre`](/hooks/stages),
[`tool.delta`](/hooks/stages), [`tool.post`](/hooks/stages) and
[`run.post`](/hooks/stages). Each hands over its own payload — a `Message`, the
whole notebook, one streamed `Part`, a `ToolCall` — and [the eight
stages](/hooks/stages) is the table of which is which.

## Asking for the run

A hook may take one argument more than its stage hands over, and that one is
the run:

```python
from core import Message, hook


@hook("model.pre")
async def trim(messages, run) -> list[Message]:
    """Keep the last twenty lines once the conversation gets long."""
    return messages[-20:] if run.step > 3 else messages
```

The arity is sniffed once, **at attach** — not at the bell. A function that
fits no shape of its stage is refused there and then:

```text
half does not fit tool.post, which hands over ToolCall, Message — take those, and run after them if you want it
```

Hooks must be async. A sync one is refused at attach with the line to write
instead: `must be async — write async def; sync work is one asyncio.to_thread
line inside it`.

## Tagging, filing, unfiling

`@hook` only tags: it writes the stage names onto the function and hands the
function straight back, so it is still an ordinary function you can call and
test. `attach` is what files it.

<Tip>
  A stage named at attach beats the tag, so an untagged function works too:
  `agent.hooks.attach(watch, "run.post")`. `attach` hands back the registry, so
  attaches chain: `agent.hooks.attach(one).attach(two)`.
</Tip>

`agent.hooks.detach(fn)` unfiles it from every stage it listened to, matched by
identity — the same object that was attached.

## The order the cards ring in

Attach order is call order. The agent's cards ring before the run's, because a
run's registry chains onto its agent's when the run is born. Within one
registry, first attached is first to hear the bell.

Two consequences worth knowing:

- A card attached (or detached) **during** a bell starts listening at the next
  one. The ring works off a snapshot, so the set of cards cannot change under
  it mid-stage.
- At [`tool.pre`](/hooks/stages), the first hook that answers with a result
  ends the ring — the cards behind it, including every one of the run's own,
  never hear that bell.

## What a hook cannot do

A hook can change the run or end it. It cannot *watch* cheaply: it is on the
critical path, it is awaited, and a slow one slows the turn. For watching,
listen on [the bus](/events/overview) instead — a listener is sync, it changes
nothing, and one that raises is logged and swallowed rather than breaking the
run.

To end a run from a hook, `raise Stop`: see [stopping and
denying](/hooks/stopping). The four cards that ship with stellar —
`Steps`, `Budget`, `Permission`, `Log` — are on [the four shipped
cards](/hooks/cards), and they are worth reading as examples even if you never
attach one.
