---
title: The four rules that come in the box
description: Steps, Budget, Permission and Log. Four small files you can read, copy and change.
---

Four rules ship with stellar, in `hooks/`. Three are hooks. One is a
listener on the [event log](/events/overview). None of them is special, and
each is a file of under forty lines.

| rule | when it runs | what it does |
| --- | --- | --- |
| `Steps(n)` | `model.pre` | gives the job n model calls, then ends it |
| `Budget(max_tokens)` | `model.post` | adds up what every reply cost, and ends the job past your limit |
| `Permission(deny, allow, ask)` | `tool.pre` | the guard at the door, refusing tools you did not allow |
| `Log(write=print)` | every event | one readable line per event, its name and what it carried |

<Note>
  Each one is a factory. Calling it hands you back a function, and the
  function is what you attach. Nothing is kept inside. One rule on the agent
  gives every job its own count, its own budget, its own answer.
</Note>

## Steps

`Steps(n: int)` gives you a `model.pre` hook. It buys exactly n replies, and
the turn after that ends before the model is ever asked.

```python run
import asyncio

from core import Agent, FakeModel, Message, ToolCall, tool
from hooks.steps import Steps


@tool
def shout(word: str) -> str:
    """Shout a word."""
    return word.upper()


asks = Message("assistant", "", [ToolCall("c1", "shout", {"word": "hi"})])
agent = Agent(FakeModel([asks, asks, asks]), [shout])
agent.hooks.attach(Steps(2))
run = asyncio.run(agent.run("keep shouting"))
print(run.step)
print(sum(m.role == "assistant" for m in run.messages))
```

```text output
3
2
```

The model asked for a tool every time and would have gone on forever. Two
replies is what it got, and the third turn stopped, so `run.step` reads 3.

## Budget

`Budget(max_tokens: int)` gives you a `model.post` hook. It adds
`input_tokens` and `output_tokens` from each reply into
`run.extra["budget.tokens"]`. Past the limit it keeps the reply you already
paid for, then ends the job.

```python run
import asyncio

from core import Agent, FakeModel, Message
from hooks.budget import Budget

paid = Message("assistant", "one",
               meta={"usage": {"input_tokens": 30, "output_tokens": 12}})
agent = Agent(FakeModel([paid]))
agent.hooks.attach(Budget(20))
run = asyncio.run(agent.run("go"))
print(run.extra["budget.tokens"])
print(run.messages[-1].text)
```

```text output
42
one
```

The total lives in `run.extra`, so it belongs to one conversation and it
rides along in a [checkpoint](/patterns/checkpoint). A reply that carries no
usage costs nothing, because not every provider counts.

## Permission

`Permission(deny=None, allow=None, ask=False)` gives you a `tool.pre` hook.
`deny` wins, then an `allow` list settles it alone, and only then is a
person asked.

```python run
import asyncio

from core import Agent, FakeModel, Message, ToolCall, tool
from hooks.permission import Permission


@tool
def rm(path: str) -> str:
    """Delete a file."""
    return "gone"


asked = Message("assistant", "", [ToolCall("c1", "rm", {"path": "/"})])
agent = Agent(FakeModel([asked, "I was not allowed."]), [rm])
agent.hooks.attach(Permission(deny={"rm"}))
run = asyncio.run(agent.run("delete everything"))
print(next(m.text for m in run.messages if m.role == "tool"))
```

```text output
denied: rm
```

`deny` and `allow` each take a set of names, or a function `(run, call)`
that answers true or false. So a rule can read the arguments, not just the
name. With `ask=True` the question goes to an
`async (question, options)` function you put in `extra["ui.ask"]`.

<Warning>
  Anything but the exact word `allow` refuses. With `ask=True` and no
  `ui.ask` anywhere, every call is refused with `denied: no ui.ask channel`.
</Warning>

## Log

`Log(write=print)` is not a hook. It is a listener, and it writes one line
per event, the name and what it carried.

```python run
import asyncio

from core import Agent, FakeModel, Message, ToolCall, tool
from hooks.logging import Log


@tool
def shout(word: str) -> str:
    """Shout a word."""
    return word.upper()


asked = Message("assistant", "", [ToolCall("c1", "shout", {"word": "hi"})])
agent = Agent(FakeModel([asked, "done"]), [shout])
agent.events.listen(Log())
asyncio.run(agent.run("shout hi"))
```

```text output
run.pre: shout hi
model.pre: 1 message
model.delta: <tool_call>
model.post: shout({'word': 'hi'})
tool.pre: shout({'word': 'hi'})
tool.post: HI
model.pre: 3 messages
model.delta: done
model.post: done
run.post: done
```

Ten events for a two-turn job. There is no `tool.delta` line because
`shout` does not stream. Narrow it down with
`agent.events.listen(Log(), "tool")` for the tool lines only, or
`agent.events.listen(Log(), run_id=run.id)` for one conversation.
