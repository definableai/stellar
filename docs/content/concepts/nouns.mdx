`core/` names twelve things. Everything else in it is one of these twelve, or
a function that moves them around.

| name | kind | what it is |
| --- | --- | --- |
| [`Part`](/reference/types) | data | One piece of a message: `type` names it, `data` holds it. |
| [`ToolCall`](/reference/types) | data | The model asking for one tool: `id`, `name`, `args`. |
| [`Message`](/reference/types) | data | One line in the conversation: `role` and `content`, plus tool and meta fields. |
| [`Model`](/reference/model) | you write it | The brain: an async `invoke(run)` that gives back one `Message`. |
| [`Tool`](/reference/tool) | you write it | One thing the agent can do: an async `execute(run, **args)`. |
| [`Hooks`](/reference/hooks) | the rules | Your rules, filed by stage: `attach`, `detach`, `fire`. |
| [`Event`](/reference/events) | data | One thing that happened: `seq`, `name`, `data`, `source`, `run_id`, `ts`. |
| [`Events`](/reference/events) | the log | What happened, and everyone watching: `emit`, `listen`, `stream`. |
| [`Agent`](/reference/agent) | the wiring | What you build once: `model`, `tools`, `hooks`, `events`, `extra`. |
| [`Run`](/reference/agent) | one job | One conversation: `id`, `messages`, `step`, `hooks`, `extra`, `emit()`. |
| [`ContractError`](/reference/signals) | signal | You wired it wrong. The message says what to type instead. |
| [`Stop`](/reference/signals) | signal | Raise it from any hook or tool to end the run cleanly. |

A thirteenth one in `core/` is a conversation, not a merge. See
[the rules](/layout).

## Helpers built on the primitives

`from core import …` gives you more than the twelve. Each of these is built
out of them, and you could write it yourself.

- **`ProviderModel`** is a Model in two steps: `encode(run)` makes the request,
  `send(run, body)` yields the reply in pieces.
- **`Provider`** is the HTTP half every provider shares: the key, the client,
  the retries. See [folders](/models/folder).
- **`Profile`** is one row from a provider's docs: the id, the sizes, what the
  model can do. See [profiles](/models/profiles).
- **`ANY`** is the profile an unknown model id falls back to, after a warning.
- **`Fallback`** is a model made of models, asked in order until one answers.
  See [fallback](/models/fallback).
- **`FakeModel`** reads its answers off a list you wrote. See
  [testing](/models/testing).
- **`ProviderError`** means the provider said no. `.status` is the HTTP status,
  or `None`.
- **`Unsupported`** means this model cannot do what the run asks, said before
  the network.
- **`@tool`** turns a plain function into a [Tool](/tools/functions): its name,
  its docstring, its signature.
- **`@hook`** tags a function with the stages it listens for. See
  [hooks](/hooks/overview).
- **`STAGES`** is the eight stage names, in order.
- **`run`** is the loop itself. `Agent.run()` builds a `Run` and hands it here.
- **`check`** reads the wiring and raises `ContractError` with the code to type
  instead.
- **`check_model`** tests a provider you wrote over three real exchanges.
  Import it from `core.conformance`. See [conformance](/reference/conformance).

<Note>
  Everything is async, and everything core calls takes the run. Sync work is
  one `asyncio.to_thread` line inside your async method. The one exception is
  an event listener, which is sync because `emit()` never waits.
</Note>
